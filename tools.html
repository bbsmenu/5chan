5chan Thread URL Generator

このツールについて

このツールは、いつもちゃんねる（5chan.jp）の
カテゴリ → 板 → 日時 を選ぶことで、
read.cgi 形式のスレッドURL を自動生成します。

使い方

  1. カテゴリを選択
  2. 板を選択
  3. スレが立った日時（>>1 の投稿日時）を入力
  4. 「生成」を押すと URL が作成されます
  5. 「開く」でスレを新しいタブで開けます
  6. 「コピー」で URL をクリップボードに保存できます

注意

  • 日時は JST（日本時間） として扱われます
  • 曜日（例：日）は入力しても無視されます
  • 生成されるURL形式：
    http://5chan.jp/test/read.cgi/板ID/UnixTime/

曜日は入っていてもOK。JSTとして扱います。
